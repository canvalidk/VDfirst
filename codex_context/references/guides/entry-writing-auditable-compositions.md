# Entry Writing: Auditable Compositions

Source: `VD docs/VD unsorted important/entry_writing_guide_auditable_compositions.md`
Status: active guidance
Code relevance: constrains entry-string composition and names the residual
audit practice the dependency graph cannot perform by itself.

## Core Understanding

An entry string has two kinds of material:

- Headword references, which are visible to the tokenizer, dependency graph,
  traces, and audits.
- Residual phrases, which are not graph-visible and work only by provoking
  reactions in the interpreter.

The honest rule is that residual phrases may only rely on reactions already
installed by grammar, general English, the relevant scientific culture,
stock formulas, prior lessons, or other auditable headword entries. If a
phrase invents a new conceptual device and that device does definitional
work, it must be promoted to an entry or replaced with installed language.

This treats novel residual machinery as the residual-layer equivalent of a
hidden import. It can also create a forward hidden import when a figure borrows
the conceptual scheme of entries that come later.

## Acceptable Residual Provenance

When reviewing an entry, each non-headword phrase should have a named backing:

- Grammar-level mechanisms: definite descriptions, presuppositions,
  default-and-defeater forms, ordinary scope idioms.
- General-English idioms, limited to their idiom strength.
- Community-installed scientific terms, such as `artifact` or `to the needed
  approximation`.
- Stock formulas the target culture already recognizes.
- Lesson-installed handles, when the intended interpreter has passed through
  the relevant lesson.
- Headword edges, which are preferable when the load can be made auditable.

Installed material still needs routing discipline. A phrase can be familiar and
still trigger bad baggage, stale slogans, or packet-known misreads.

## Residual Provenance Ledger

For each entry packet, keep a small ledger for residual phrases:

| Phrase | Backing |
| --- | --- |
| `artifact of the frame itself` | Scientific-culture reaction: discount it and check the apparatus; matches packet vocabulary and trace warning vocabulary. |

The ledger should have no row whose backing is only the writer's private
invention. If such a row appears, either promote the figure into its own entry
or replace the phrase with installed material.

It is especially useful when residual vocabulary matches simulator vocabulary:
for example, an entry phrase using `artifact` and a trace warning named
`frame-artifact warning` keep the string and the trace auditable against each
other.

## Quick Audit Test

Before installing an entry string, ask of every non-headword phrase:

1. Who installed the reaction this phrase relies on: the culture, the language,
   the lesson, or the writer?
2. If the writer installed it, which entry carries it?
3. Does the phrase stay at installed strength, or does it extend an idiom or
   metaphor into a new system?
4. Does the figure borrow machinery from entries that come later?

Related entry-writing rules: avoid attitude verbs in entry strings; use
practice words such as `used as standard` rather than `accepted` or `treated
as`. Avoid imperatives and agent-directed deontics; declarative entry strings
remain the default.
