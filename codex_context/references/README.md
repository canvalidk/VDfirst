# Cross-Branch References

This area is reserved for short guides, copied extracts, or pointers from the
Theory and Newton branches. It should help Code use those branches as context
without turning this repository into the full archive.

Suggested layout:

- `theory/` for conceptual foundations, philosophy, and VD design principles.
- `newton/` for entry design notes, Newton problem traces, and domain choices.
- `guides/` for implementation-facing instructions, workflows, or handoff
  notes that apply across branches.

When adding reference files, prefer small markdown guides with source labels:

```markdown
# Title

Source: path or document name from the original branch
Status: rough draft / active guidance / historical
Code relevance: why this matters for the simulator
```
