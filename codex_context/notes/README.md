# Working Notes

This folder is for short, dated Code-branch notes that are not yet stable
enough to become goals, architecture notes, or specs.

Suggested filename format:

```text
YYYY-MM-DD-topic.md
```

Keep working notes small. When a note becomes stable, fold it into
`GOALS.md`, `CODE_ARCHITECTURE.md`, `TRACE_POC.md`, or a formal spec.
