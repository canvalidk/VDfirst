# Examples

This folder is for examples that make the simulator understandable and
presentable.

Examples should be small enough to read and stable enough to test against
later. They can begin as sketches and become golden examples over time.

## Planned Examples

- `toy-force-trace.md` - tiny dictionary trace for force, mass, and
  acceleration.
- `atwood-level2-placeholder.md` - placeholder for the Atwood trace once the
  Newton branch version is ready to import or summarize.

## Maturity Labels

- Sketch: illustrative, not a code contract.
- Golden: expected behaviour; should have tests or fixtures.
- Historical: useful for context, not current expected behaviour.
